Registers are data slots in the VM. This VM's registers are 128 bits long.

During this document you will encounter a column called RW which stands for Read-Write. This column indicates whether a register can be read or written, and its value are as below:

- TT: Read: True | Write: True
- TF: Read: True | Write: False
- FT: Read: False | Write: True
- FF: Read: False | Write: False

Registers, regardless of their categories, are of two types: special-purpose and general-purpose. Special-purpose registers have their type predefined, whilst general-purpose registers don't have a specific type. Thus, all general-purpose registers have a shadow counterpart that stores the type-tag of the data being held in the original register.

== Global Registers

Global registers are globally accessible in a running program and are nor thread-based nor context-frame-based.

=== Special-Purpose Global Registers

.Special-Purpose Global Registers
|===
| Name | Symbol | Type | RW | Purpose

| Program ID | PID | I128U | TF | Holds the ID of the current program being executed. This ID is randomly generated when the program is booted on the VM.
| Boot Timestamp | BTS | I128U | TF | Holds the timestamp of when the program was booted on the VM.
| Zero Register | ZR | I128U | TT | Will always yield a 128-bit long zero filled I128U. Any data written to it will be discarded.
|===

=== General-Purpose Global Registers

CAUTION: Using general-purpose global registers is highly discouraged unless absolutely necessary or when knowing what should be done properly.

.General-Purpose Global Registers
|===
| Name | Symbol | Type | RW | Purpose

| Global Register 0 | GR0 | Variable | TT | General-purpose
| Global Register 1 | GR1 | Variable | TT | General-purpose
5+^|...
| Global Register 15 | GR15 | Variable | TT | General-purpose
|===

.General-Purpose Shadow Global Registers
|===
| Name | Symbol | Type | RW | Purpose

| Global Register 0's Shadow | #GR0 | I8U | TF | Holds the type-tag of the data stored in the GR0 register.
| Global Register 1's Shadow | #GR1 | I8U | TF | Holds the type-tag of the data stored in the GR1 register.
5+^|...
| Global Register 15's Shadow | #GR15 | I8U | TF | Holds the type-tag of the data stored in the GR15 register.
|===

== Thread Registers

Thread registers are only accessible inside of a thread itself. Since a context-frame is architecturally inside a thread, a context-frame can as well access its parent thread's registers.

=== Special-Purpose Global Registers

.Special-Purpose Global Registers
|===
| Name | Symbol | Type | RW | Purpose

| Thread ID | TID | I128U | TF | Holds the ID of the current thread. This ID is randomly generated when a thread is spawned.
| Thread Timestamp | TTS | I128U | TF | Holds the timestamp of when the thread is spawned.
| Instruction Pointer | IP | I128U | TF | Holds the pointer referencing the current instruction being executed in the thread.
|===

== Context-Frame Registers

Context-frame registers are only accessible inside the frame itself.

=== Special-Purpose Context-Frame Registers

.Special-Purpose Context-Frame Registers
|===
| Name | Symbol | Type | RW | Purpose
| Return Pointer | RP | I128U | TF | Holds the pointer of where the parent context-frame was left off.
| Return Type | RT | I8U | TF | Holds the type of the returned payload.
| Return Register | RR | Variable | TF | Holds the payload of a return from a function.
| Catch-block Pointer | CBP | I128U | TF | Holds the pointer referencing the catch-block that should catch a thrown error in case of it ever happening.
| Exception Flag | EXF | BOOL | TF | Holds a boolean indicating whether an exception has been thrown.
| Exception Register | EXR | I128U | TF | Holds the exception operand thrown by a child context-frame to be read by the catch-block of the current context-frame.
| Overflow Flag | OF | BOOL | TF | Indicates whether the most recent signed arithmetic operation had an overflow.
| Carry Flag | CF | BOOL | TF | Indicates whether the most recent unsigned arithmetic operation wrapped around.
| Zero Denominator Flag | ZDF | BOOL | TF | Indicates whether the most recent division has had a zero denominator.
|===
