Opcodes are used to instruct the VM to perform a certain action.

. The symbol R\{n} (e.g. Rx, Ry, R1, R2, ...) indicates a register.
. The symbol $\{n} (e.g. $x, $y, $1, $2, ...) indicates an operand that can be either a register, a constant or an immediate value.
. The symbol F\{n} (e.g. Fx, Fy, F1, F2, ...) indicates a function.
. The symbol T\{n} (e.g. Tx, Ty, T1, T2, ...) indicates a type.

.Basic Integer Arithmetic
|===
| Opcode | Binary | Operands | Semantic | Description

| IADD | | Rx $1 $2 | Rx = $1 + $2 | Adds two integers and stores the result in a register.
| ISUB | | Rx $1 $2 | Rx = $1 - $2 | Subtracts two integers and stores the result in a register.
| IMUL | | Rx $1 $2 | Rx = $1 * $2 | Multiplies (signed) two integers and stores the result in a register.
| IMULU | | Rx $1 $2 | Rx = $1 * $2 | Multiplies (unsigned) two integers and stores the result in a register.
| IDIV | | Rx $1 $2 | Rx = $1 / $2 | Divides (signed) two integers and stores the result in a register.
| IDIVU | | Rx $1 $2 | Rx = $1 / $2 | Divides (unsigned) two integers and stores the result in a register.
| IMOD | | Rx $1 $2 | Rx = $1 % $2 | Stores the (signed) modulus of two integers in a register.
| IMODU | | Rx $1 $2 | Rx = $1 % $2 | Stores the (unsigned) modulus of two integers in a register.
| INEG | | Rx $1 | Rx = -$1 | Stores the negated value of an integer in a register.
|===

.Advanced Integer Arithmetic
|===
| Opcode | Binary | Operands | Semantic | Description

| IMIN | | Rx $1 $2 | Rx = $1 < $2 ? $1 : $2 | Copies the value of the lesser value between $1 and $2 into Rx for integers.
| IMAX | | Rx $1 $2 | Rx = $1 > $2 ? $1 : $2 | Copies the value of the larger value between $1 and $2 into Rx for integers.
| IABS | | Rx $1 | Rx = \|$1\| | Copies the absolute value of $1 into Rx for integers.
| IINC | | Rx | Rx = Rx + 1 | Increases the value of Rx by one and stores it back.
| IDEC | | Rx | Rx = Rx - 1 | Decreases the value of Rx by one and stores it back.
|===

.Bitwise
|===
| Opcode | Binary | Operands | Semantic | Description

| AND | | Rx $1 $2 | Rx = $1 & $2 | Stores the bitwise AND result of two operands in a register.
| OR | | Rx $1 $2 | Rx = $1 \| $2 | Stores the bitwise OR result of two operands in a register.
| XOR | | Rx $1 $2 | Rx = $1 ^ $2 | Stores the bitwise XOR result of two operands in a register.
| NOT | | Rx $1 | Rx = ~$1 | Stores the bitwise NOT result of an operand in a register.
| LLS | | Rx $1 $2 | Rx = $1 << $2 | Logically shifts $1 by $2 bits to the left and stores the result in a register.
| LRS | | Rx $1 $2 | Rx = $1 >> $2 | Logically (unsigned) shifts $1 by $2 bits to the right and stores the result in a register.
| ARS | | Rx $1 $2 | Rx = $1 >>> $2 | Arithmetically (signed) shifts $1 by $2 bits to the right and stores the result in a register.
|===

| FLT | | Rx $1 $2 | Rx = $1 < $2 | Stores the boolean value resulted from the less-than test of two float operands.
| FLE | | Rx $1 $2 | Rx = $1 \<= $2 | Stores the boolean value resulted from the less-than-or-equal test of two float operands.
|===

.Control Flow
|===
| Opcode | Binary | Operands | Semantic | Description

| JMP | | $OFFSET | - | Unconditionally jumps to the given offset.
| JMPT | | $OFFSET $COND |  | Jumps to the $OFFSET offset if $COND is true (1).
| JMPF | | $OFFSET $COND |  | Jumps to the $OFFSET offset if $COND is false (0).
| JMPV | | $OFFSET $COND $SWITCH | | Jumps to the $OFFSET offset based on $COND being true if $SWITCH is true, or $COND being false if $SWITCH is false.
| ENOUGH | | |  | Terminates the program.
| ENOUGHX | | $1 | | Terminates the program and exits with the $1 code.
| NOP | | | | Does nothing and moves to the next instruction.
|===

.Functions and Calls
|===
| Opcode | Binary | Operands | Semantic | Description

| CALL | | Rx F1 Ry | Rx = F1([Ry + (64 * 0)], [Ry + (64 * 1)], [Ry + (64 * 2)], ...) | Push the return address, jump to the F1 function using the arguments starting from the base register (Ry) moving forward until the required counts of arguments is satisfied for the given function. Then stores the returned value of the function in the Rx register.
| RET | | $1 | - | Return the value of $1 then pop the return address and jump to it.
|===

.Data Operations
|===
| Opcode | Binary | Operands | Semantic | Description

| COP | | Rx $1 | Rx = $1 | Copy the value of $1 into the Rx register.
| COPIF | | Rx $COND $1 $2 | Rx = $COND ? $1 : $2 | Conditionally sets Rx equal to $1 if $COND is true (1) or $2 if otherwise.
| SWAP | | Rx Ry | temp = Rx; Rx = Ry; Ry = temp; | Swaps the values of the Rx and the Ry registers.
| LOAD | | Rx $ADDR | Rx = memory[$ADDR] | Copy the value from the memory at the address of $ADDR into the Rx register.
| LOADO | | Rx $ADDR $OFFSET | DST = memory[$ADDR + $OFFSET] | Copy the value from the memory at the address of $ADDR plus the $OFFSET offset into the Rx register.
| STR | | $ADDR $1 | memory[$ADDR] = $1 | Copy the value of $1 into the memory at the address of $ADDR.
| STRO | | $ADDR $1 $OFFSET | memory[$ADDR + $OFFSET] = $1 | Copy the value of $1 into the memory at the address of $ADDR by an offset $OFFSET.
|===

.Types and Tags
|===
| Opcode | Binary | Operands | Semantic | Description

| EXTAG | | Rx $1 | | Extract the tag bits of $1 and store it into the Rx register.
| EXTVAL | | Rx $1 | | Extract the value bits of $1 and store it into the Rx register.
| ISTYPE | | Rx $1 T1 | | Set Rx to true (1) if $1 is of type T1.
| ISNOTTYPE | | Rx $1 T1 | | Set Rx to true (1) if $1 is not of type T1.
| ISFARTYPE | | Rx $1 T1 | | Set Rx to true (1) if $1 as a pointer references to a value of type T1 (indirect type).
| ISNOTFARTYPE | | Rx $1 T1 | | Set Rx to true (1) if $1 as a pointer doesn't reference to a value of type T1 (indirect type).
| I2F | | Rx $1 | | Convert $1 (int) to float and store it in the Rx register.
| F2I | | Rx $1 | | Convert $1 (float) to int and store it in the Rx register.
| I2P | | Rx $1 | | Convert $1 (integer) to a pointer and store it in Rx register.
| P2I | | Rx $1 | | Convert $1 (pointer) to an integer and store it in the Rx register.
|===
