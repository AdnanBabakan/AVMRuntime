Opcodes are used to instruct the VM to perform a certain action.

. The symbol R\{n} (e.g. Rx, Ry, R1, R2, ...) indicates a register.
. The symbol $\{n} (e.g. $x, $y, $1, $2, ...) indicates an operand that can be either a register, a constant or an immediate value.
. The symbol F\{n} (e.g. Fx, Fy, F1, F2, ...) indicates a function.
. The symbol T\{n} (e.g. Tx, Ty, T1, T2, ...) indicates a type.
. The symbol :\{n} (e.g. :x, :y, :1, :2, ...) indicates a label.
. The symbol <\{n}> (e.g. <x>, <y>, <1>, <2>, ...) indicates a scaled offset. A scaled offset is an integral value that its meaning depends on the memory region it is being applied on. A scaled offset of _N_ in a memory region of elements with _W_ bits width, refers to an offset of _N*W_ bits. For instance, an offset of 2 in an 8-bit memory region means 16 bits, or an offset of 10 in a 64-bit memory region means 640 bits. An offset itself can be retrieved from a register, a constant or an immediate value. But it must be an integer.

.Integer Arithmetic
|===
| Name | Opcode | HEX | Operands | Semantic | Description

6+^| *Basic*
| Integer Addition | IADD | | Rx $1 $2 | Rx = $1 + $2 | Adds two integers and stores the result in a register.
| Integer Subtraction | ISUB | | Rx $1 $2 | Rx = $1 - $2 | Subtracts two integers and stores the result in a register.
| Integer Multiplication | IMUL | | Rx $1 $2 | Rx = $1 * $2 | Multiplies two integers and stores the result in a register.
| Integer Division | IDIV | | Rx $1 $2 | Rx = $1 / $2 | Divides (signed) two integers and stores the result in a register.
| Unsigned Integer Division | IDIVU | | Rx $1 $2 | Rx = $1 / $2 | Divides (unsigned) two integers and stores the result in a register.
| Integer Modulus | IMOD | | Rx $1 $2 | Rx = $1 % $2 | Stores the (signed) modulus of two integers in a register.
| Unsigned Integer Modulus | IMODU | | Rx $1 $2 | Rx = $1 % $2 | Stores the (unsigned) modulus of two integers in a register.
| Integer Negation | INEG | | Rx $1 | Rx = -$1 | Stores the negated value of an integer in a register.

6+^| *Advanced*
| Minimum Integer | IMIN | | Rx $1 $2 | Rx = $1 < $2 ? $1 : $2 | Copies the value of the lesser value between $1 and $2 into Rx for integers.
| Maximum Integer | IMAX | | Rx $1 $2 | Rx = $1 > $2 ? $1 : $2 | Copies the value of the larger value between $1 and $2 into Rx for integers.
| Absolute of Integer | IABS | | Rx $1 | Rx = \|$1\| | Copies the absolute value of $1 into Rx for integers.
| Increase Integer | IINC | | Rx | Rx = Rx + 1 | Increases the value of Rx by one and stores it back.
| Decrease Integer | IDEC | | Rx | Rx = Rx - 1 | Decreases the value of Rx by one and stores it back.

.Control Flow
|===
| Name | Opcode | HEX | Operands | Semantic | Description

6+^| *Jumps*
| Unconditional Jump | JMP | | :x | - | Unconditionally jumps to the given label.
| Conditional Jump (if true) | JMPT | | :x $COND |  | Jumps to the :x label if $COND is true (1).
| Conditional Jump (if false) | JMPF | | :x $COND |  | Jumps to the :x label if $COND is false (0).

6+^| *Halting*
| Termination | ENOUGH | | |  | Terminates the program.
| Termination (with exit code) | ENOUGHX | | $1 | | Terminates the program and exits with the $1 code.
| Assertion | ASSERT | | $COND $1 | | Terminates the program and exists with the $1 code if $COND is false.

6+^| *Special*
| No-operation | NOP | | | | Does nothing and moves to the next instruction.

.Functions and Calls
|===
| Name | Opcode | HEX | Operands | Semantic | Description

| Function Call | CALL | | Rx F1 [$1 $2 $3 ...] | Rx = F1($1, $2, $3, ...) | Push the return address, jump to the F1 function. Then stores the returned value of the function in the Rx register.
| Function Return | RET | | $1 | - | Return the value of $1 then pop the return address and jump to it.

.Data Operations
|===
| Name | Opcode | HEX | Operands | Semantic | Description

6+^| *General*
| Copy | COP | | Rx $1 | Rx = $1 | Copy the value of $1 into the Rx register.
| Conditional Copy | COPIF | | Rx $COND $1 $2 | Rx = $COND ? $1 : $2 | Conditionally sets Rx equal to $1 if $COND is true (1) or $2 if otherwise.
| Swap | SWAP | | Rx Ry | temp = Rx; Rx = Ry; Ry = temp; | Swaps the values of the Rx and the Ry registers.

6+^| *Scaled Memory*
| Load | LOAD | | Rx $POINTER | Rx = memory[$POINTER] | Copy the value from the memory at the address of $POINTER into the Rx register.
| Load (with offset) | LOADO | | Rx $POINTER <x> | Rx = memory[$POINTER + <x>] | Copy the value from the memory at the address of $POINTER plus the <x> offset into the Rx register.
| Store | STR | | $POINTER $1 | memory[$POINTER] = $1 | Copy the value of $1 into the memory at the address of $POINTER.
| Store (with offset) | STRO | | $POINTER $1 <x> | memory[$POINTER + <x>] = $1 | Copy the value of $1 into the memory at the address of $POINTER by an offset of <x>.

6+^| *Unscaled Memory*
| Byte Load | BLOAD | | Rx $POINTER $1 | Rx = memory[$POINTER] | Copy $1 bytes of data from the memory at the address of $POINTER into the Rx register (used for raw-memory operations).
| Byte Load (with offset) | BLOADO | | Rx $POINTER $1 $OFFSET | Rx = memory[$POINTER + $OFFSET] | Copy $1 bytes of data from the memory at the address of $POINTER by an offset of $OFFSET bytes into the Rx register.
| Byte Store | BSTR | | $POINTER $1 $BYTES | | Copy $BYTES bytes of data from $1 into the memory at the address of $POINTER.
| Byte Store (with offset) | BSTRO | | $POINTER $1 $BYTES $POINTER_OFFSET $DATA_OFFSET | | Copy $BYTES bytes of data starting from an offset of $DATA_OFFSET bytes from $1 into the memory at the address of $POINTER by an offset bytes.
|===

6+^| *Logical (Comparison)*
6+|
All the comparisons made on vectors return a mask. A mask is always a vector of the same size with the same count of lanes as the original vector, but the lanes are of the unsigned int type correspondent of the lane size of the original vector. A mask's lane is filled in zeros if the comparison resulted in a falsely value, and in ones if it resulted in a truely value.
